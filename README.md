# 🎉 Semana de Aniversario Uniremington

Página web desarrollada para presentar y documentar las actividades realizadas durante la **Semana de Aniversario Uniremington**.

El proyecto busca ofrecer una experiencia visual, moderna e interactiva donde los estudiantes puedan consultar los diferentes eventos, fechas, información, fotografías y videos de las actividades.

## 🌟 Características

* 🎓 Diseño inspirado en la comunidad universitaria.
* 🎉 Fondo animado con confeti y efectos visuales.
* 🗓️ Cronograma de actividades.
* 🃏 Tarjetas interactivas para cada evento.
* 🖼️ Espacios para fotografías y evidencias.
* 🎥 Sección para videos de las actividades.
* 📊 Integración con información almacenada en Excel.
* ✨ Efectos `hover` sobre tarjetas e imágenes.
* 📱 Diseño responsive para computador, tablet y celular.
* 🔗 Enlaces para consultar la información detallada de cada actividad.
* 🎨 Interfaz moderna, colorida y adaptable.

## 🎥 Videos de las actividades

La página cuenta con una sección dedicada a los **videos de la Semana de Aniversario**, donde se presentan diferentes momentos de las actividades realizadas.

Los videos funcionan como evidencia audiovisual de la participación y permiten conservar los momentos más importantes de cada evento.

Se pueden incluir videos correspondientes a:

* 🎬 Apertura Uniremington Fest.
* 🎤 Talentos Uniremington.
* 🎯 Juegos – Cultura General.
* 🎭 Declamadores Invitados.
* 🏆 Entrega de Distinciones.
* 👨‍👩‍👧‍👦 Día de la Familia Uniremington y Feria Empresarial.

Los videos pueden incorporarse mediante archivos locales o enlaces a plataformas como YouTube, dependiendo de la forma de entrega del proyecto.

## 📸 Evidencias fotográficas

Las fotografías utilizadas en el proyecto corresponden a las actividades realizadas durante la Semana de Aniversario.

Las evidencias deben cumplir con las siguientes condiciones:

* 📷 Las fotografías deben ser tipo selfie.
* 👤 El estudiante debe ser claramente identificable.
* 📅 Las fotografías deben corresponder a la actividad realizada.
* 🗓️ Deben coincidir con la fecha del evento.
* 👥 Si la participación es grupal, todos los integrantes deben aparecer en la fotografía.
* ▶️ Se debe incluir una fotografía del inicio y una fotografía del final de la actividad.

## 🎥 Sección multimedia

El proyecto incorpora fotografías y videos como parte de las evidencias de las actividades.

Los videos permiten complementar las fotografías y mostrar diferentes momentos de la Semana de Aniversario.

Para reproducir archivos de video locales se utiliza la etiqueta HTML5:

```html
<video controls>
    <source src="videos/apertura.mp4" type="video/mp4">
    Tu navegador no soporta la reproducción de videos.
</video>
```

## ▶️ Ejecución del proyecto

Para visualizar el proyecto:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que las carpetas `img`, `videos` y `excel` estén correctamente ubicadas.
4. Abrir el archivo `index.html` en el navegador.
5. Verificar que las imágenes, videos y enlaces funcionen correctamente.

También se puede utilizar **Live Server** en Visual Studio Code para ejecutar la página de manera local.
